# Flow — builds

Compiled builds of the **Flow** panel for Adobe After Effects. Every installed
copy of Flow checks `update.json` here and updates itself from these files.

The source code lives in a separate private repository. Nothing here is written
by hand — it is published by `npm run publish:update`.

Current version: **0.2.0**

## Installing Flow for the first time

Ask for the installer zip. Once Flow is installed, it keeps itself up to date:
the dot at the top right of the panel turns green when a new build lands here.
